I will be using a videogame library that one could update to keep track of games they have completed.

The information each game would have would be:
    - ID, Title, Dev, Genre, Platform, Release Year, Completed, and Rating.
The collection types I will use will be:
    - A Hashmap to store the entities in the list with ID numbers to be able to call on them easier.
    - An Array List to be able to display pull results easier.

I will organize the items utilizing a filter that can display games that share a genre, dev, etc. Additionally everything will have an ID number so pulling up a specific entity will be accomplished through said ID.
